# DynamoWorkflow
My custom Dynamo Workflow made possible by the Dynamo community
More info to be added soon



1.	DY	= Verzija Dynama za koju je namenjen (Trenutno: 1.3, 2.0, 2.3)

2.	Namena
* P = Proizvodna skripta
* A	= Arhitektonska skripta
* B	= Bim Management ?

3.	Red korišćenja
* 2 	= Druga po redu važnosti ili korišćenja

4.	Verzija
* .0	= Osnovna/originalna verzija skripte, 
* .1 	= Podverzija - može imati neke dodatke ili bilo šta drugo korisno, ali se ne koristi često

5.	Opis
* IME	= Kratak opis funkcije
